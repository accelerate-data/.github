# Accelerate Data

Vibedata, your data engineering agent. Accelerate Data builds it.

Every change runs apart from production on your data platform, and the agent works inside that isolation, from intent to operations. Learn more at [getVibedata.ai](https://www.getvibedata.ai).

## Vibedata

| Repository | What it holds |
| --- | --- |
| [vibedata-official](https://github.com/accelerate-data/vibedata-official) | Skill library and plugin marketplace for Vibedata |
| [vibedata-cookbooks](https://github.com/accelerate-data/vibedata-cookbooks) | Paste-and-adapt data engineering Recipes for Vibedata Studio |
| [homebrew-tap](https://github.com/accelerate-data/homebrew-tap) | Homebrew tap for Accelerate Data command-line tools |
| [fabric-semantic-model](https://github.com/accelerate-data/fabric-semantic-model) | Skills for designing, authoring, and validating Microsoft Fabric semantic models |
| [vd-dbt-elementary-fabricspark](https://github.com/accelerate-data/vd-dbt-elementary-fabricspark) | Elementary data observability for dbt on Microsoft Fabric Lakehouse |
| [vd-dbt-fabricspark](https://github.com/accelerate-data/vd-dbt-fabricspark) | Fork of the dbt adapter for Microsoft Fabric Lakehouse on Spark |
